# ⚛️ Enterprise RAG 2.0

**Enterprise RAG 2.0** — автономный корпоративный программный комплекс вопросно-ответной аналитики документов на основе гибридного поиска (Okapi BM25 + Dense 768-D + Reciprocal Rank Fusion) с защитой от галлюцинаций и поддержкой локального инференса.

---

## 🌟 Ключевые возможности

1. **🚀 Полная автономность (Turnkey Local):**
   - Автоматический поиск и управление локальным сервером LM Studio через CLI (`lms.exe`).
   - Загрузка эмбеддингов (`text-embedding-nomic-embed-text-v1.5`) и LLM (`qwen2.5-14b-instruct-1m`) в GPU в 1 клик.
   - Аппаратная защита VRAM: запуск с флагом `-c 8192 --gpu max -y` предотвращает перегрузку видеопамяти.
2. **🌐 Двойной режим работы (Dual-Mode):**
   - **Автономный режим**: Управление локальным сервером и видеокартой прямо из интерфейса.
   - **Клиентский режим**: Подключение к любому внешнему или сетевому URL (LM Studio, vLLM, Ollama, OpenAI-compatible API).
3. **🔍 Двухуровневый гибридный поиск (Hybrid Retrieval):**
   - Точный поиск по датам, номерам приказов и терминам через **Okapi BM25** с русским стеммингом.
   - Концептуальный поиск по смыслу через плотные векторы **Nomic Embed Text v1.5 (768-D)**.
   - Слияние списков ранжирования по алгоритму **Reciprocal Rank Fusion (RRF, k=60)**.
4. **🧠 Оптимизация внимания модели (Lost-in-the-Middle Mitigation):**
   - Специальный алгоритм раскладки чанков размещает наиболее релевантные факты по краям контекста, устраняя провалы внимания трансформера в середине длинного промпта.
5. **🛡️ Корпоративная безопасность и надежность:**
   - **100% On-Premises (Air-Gapped):** Ни один байт информации не отправляется во внешние облака.
   - **Строгая XML-изоляция:** Текст документов изолирован внутри тегов `<context>`, блокируя Prompt Injection.
   - **Zero-Retrieval фильтр:** Модель прямо заявляет об отсутствии данных, если информации нет в регламентах.
   - **Аппаратный CJK-фильтр:** Потоковая очистка от паразитных иероглифов при многоязычной генерации.
6. **📊 Презентационный контур для заказчика:**
   - Отдельный раздел «Архитектура и демонстрация» с диаграммами, таблицей сравнения и бенчмарками.
   - Поисковый плейграунд для демонстрации качества извлечения первоисточников без вызова LLM.
   - Drag-and-drop загрузка документов (PDF, TXT, MD) с инкрементальной индексацией.

## 🚀 Быстрый запуск

### Вариант 1. Десктопный запуск в 1 клик (Windows):
Дважды щелкните файл:
```bat
start_rag.bat
```
*(Или выполните `python run_app.py`)*. Откроется нативное десктопное окно с темной темой **RAG Studio**.

### Вариант 2. Запуск в браузере:
```bash
streamlit run rag_gui.py
```
