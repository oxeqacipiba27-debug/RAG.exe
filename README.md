# EXSCIO RAG — Client Edition

> Автономный клиентский комплекс вопросно-ответного взаимодействия с корпоративной базой знаний.

EXSCIO RAG Client Edition — это защищенная клиентская версия корпоративной RAG-системы, спроектированная специально для сотрудников и конечных пользователей. Приложение подключается напрямую к вашему центральному серверу инференса, исключая необходимость в локальных дискретных GPU на рабочих местах пользователей.

---

## 🌟 Ключевые возможности и ограничения

### 1. Подключение строго к основному серверу
- Клиентская версия заблокирована на адрес вашего корпоративного сервера (`MAIN_SERVER_URL` в `.env`).
- В интерфейсе полностью удалены селекторы бэкендов, кнопки перезапуска/выгрузки моделей и инструменты администрирования (`server_manager`).

### 2. Защищенная база знаний (Read-Only)
- База знаний и векторный индекс (`rag_index.json`) защищены от модификации и работают строго в режиме чтения.
- Исключены случайное удаление файлов, загрузка неавторизованных документов и запуск ресурсоемкой переиндексации.
- Доступен удобный **Каталог документов** с просмотром источников, страниц и мгновенным поиском подтверждающих цитат.

### 3. Безопасные стили ответов
- Системный промпт и критические гиперпараметры изолированы от изменений.
- Пользователю доступен выбор стиля ответа:
  - 💼 **Деловой / Сбалансированный** (по умолчанию)
  - ⚡ **Краткий и точный**
  - 📖 **Развернутый / Экспертный**

### 4. Производственное качество ответов
- **Двухуровневый гибридный поиск**: Okapi BM25 + Dense 768-D (Nomic Embed) с ранжированием по Reciprocal Rank Fusion (RRF k=60).
- **Lost-in-the-Middle mitigation**: оптимальное U-образное переупорядочивание контекста в промпте.
- **Подтверждающие первоисточники**: каждый ответ снабжен списком точных первоисточников со страницами и фрагментами текста.
- **Защита от галлюцинаций (Zero-Retrieval)**: честный отказ при отсутствии информации в документах.
- **Потоковый CJK-фильтр**: автоматическое удаление паразитных иероглифов при инференсе.

## 🚀 Быстрый старт

### Требования
- Python 3.10+
- Сетевой доступ к основному серверу инференса (по умолчанию `http://127.0.0.1:1234/v1`)

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка подключения
Скопируйте пример файла окружения:
```bash
copy .env.example .env
```
При необходимости укажите IP-адрес или домен вашего основного сервера в параметре:
```env
MAIN_SERVER_URL=http://<IP_ИЛИ_ДОМЕН_ОСНОВНОГО_СЕРВЕРА>:1234/v1
```

### 3. Запуск приложения

#### В Windows:
- Двойной клик по **`start_client.bat`** (или тихий запуск через **`start_client.vbs`** без окна консоли).

#### Через командную строку:
```bash
python run_client.py
```
*(Для запуска в режиме консоли используйте флаг `--console`)*
