# Стандарты архитектуры и правила проекта (EXSCIO RAG Client Edition)

## 1. Строгое подключение к основному серверу (Main Server Lockdown)
- **Правило**: Клиентская версия подключается ИСКЛЮЧИТЕЛЬНО к центральному серверу инференса (`MAIN_SERVER_URL`), настроенному администратором в файле `.env`.
- **Ограничения**: В пользовательском интерфейсе полностью удалены любые селекторы провайдеров (Ollama / LM Studio / Docker / Custom URL), поля ручного ввода адресов и вызовы локального управления серверами (`server_manager`).

---

## 2. Безопасность и режим «Только для чтения» (Read-Only Knowledge Base)
- **Правило**: Корпоративная база знаний (`rag_index.json`) работает строго в режиме чтения.
- **Ограничения**: В клиентском интерфейсе отсутствуют кнопки загрузки файлов, удаления, очистки и переиндексации базы данных. Пользователю доступны исключительно поиск, чтение цитат и просмотр каталога документов.
- **Защита промптов**: Редактирование системной инструкции заблокировано. Пользователю доступен только безопасный выбор предустановленного стиля ответа (Деловой / Краткий / Развернутый).

---

## 3. Автоматическая очистка портов перед стартом интерфейса
- Перед запуском веб-сервера Streamlit в загрузчике (`run_client.py` / `start_client.bat`) обязательно сканировать целевой порт (`8501`) через `netstat -ano` и завершать любые оставшиеся зомби-процессы Python через `taskkill /F /PID`.

---

## 4. Стандарты кодировки консоли Windows (cp1251 vs UTF-8)
- Во всех Python-скриптах на первой исполняемой строке выполнять `sys.stdout.reconfigure(encoding="utf-8")`.
- В консольных логах батч-файлов использовать маркеры совместимости `[OK]`, `[!]`, `[X]` во избежание `UnicodeEncodeError`.

---

## 5. Таймауты сетевых запросов к LLM
- Таймауты HTTP-запросов к основному серверу генерации должны составлять не менее 20–30 секунд (в стриминговом режиме — до 90 секунд), учитывая возможное время формирования развернутых ответов моделью 14B.

---

## 6. Разделение ресурсов: Эмбеддинги на CPU
- Векторизация поисковых запросов пользователя на стороне клиента выполняется строго на процессоре (`device="cpu"`), обеспечивая минимальные требования к клиентскому оборудованию.
