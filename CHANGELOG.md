## [2.2.0] — 2026-11-05

### 🪟 Выпуск автономного клиентского пакета для Windows 10/11 (`RAG.exe-windows/`)

- **Выделенная автономная директория (`RAG.exe-windows/`)**:
  - Полная адаптация клиентской RAG-системы EXSCIO под операционную систему Windows 10/11 (64-bit).
- **Специализированные пакетные лаунчеры Windows (`*.bat`)**:
  - `start.bat`: универсальный лаунчер с автосозданием `.env`, поиском интерпретатора Python (`venv`, `.venv`, `python`, `py -3`) и плавным переходом на браузер при отсутствии pywebview.
  - `start_rag.bat`: быстрый запуск приложения RAG.
  - `start_lmstudio.bat`: автоматическое переключение профиля на LM Studio (:1234) и старт.
  - `start_ollama.bat`: переключение профиля на службу Ollama (:11434) и старт.
  - `start_docker.bat`: предварительная проверка подсистемы WSL2 (`wsl -l -q`) по правилу 4 GEMINI.md, запуск Docker Compose и старт.
  - `stop_docker.bat`: остановка контейнеров Docker (`docker compose down`).
  - `switch_backend.bat`: консольное интерактивное меню быстрого переключения между всеми 4 бэкендами.
  - `start_api.bat`: запуск интеграционного FastAPI/SSE сервера.
  - `start_telegram_bot.bat`: запуск Telegram-бота на базе aiogram 3.x.
- **Интеграция нативного десктопного окна Windows (`run_app.py`)**:
  - Поддержка Microsoft Edge WebView2 (`gui='edgechromium'`) и WinForms (`gui='winforms'`) с иконкой `rag_icon.ico`.
  - Управление процессами и портами через Windows `netstat -ano` и `taskkill /F /PID` (правило 3 GEMINI.md).
  - Нативные всплывающие уведомления рабочего стола через PowerShell BalloonTip.
  - Гарантированная выгрузка моделей из GPU при выходе через `server_manager.unload_all_models()` (`lms unload --all`).
- **Соответствие стандартам кодировки консоли Windows (Правило 5 GEMINI.md)**:
  - Автоматическая переконфигурация UTF-8 во всех скриптах через `sys.stdout.reconfigure(encoding="utf-8")`.
  - Замена Unicode-эмодзи в консольных логах на ASCII-маркеры `[OK]`, `[!]`, `[X]`, исключающие сбои `cp1251 UnicodeEncodeError`.
- **Обнаружение бэкендов на Windows (`server_manager.py`)**:
  - Поддержка `lms.exe` в `%USERPROFILE%\.lmstudio\bin\lms.exe` и `%LOCALAPPDATA%`.
  - Поддержка `ollama.exe` в `%LOCALAPPDATA%\Programs\Ollama` и `C:\Program Files\Ollama`.
  - Поддержка Docker Desktop и проверка доступности WSL2 (`is_wsl2_available`).
  - Поиск `nvidia-smi.exe` в `C:\Windows\System32` и `C:\Program Files\NVIDIA Corporation\NVSMI`.
- **Исчерпывающий набор тестов (`tests/test_windows_components.py`, `tests/test_windows_ui_e2e.py`)**:
  - 100% прохождение проверки компиляции байткода всех модулей.
  - Модульные тесты ядра `rag_engine.py`: AppConfig, VectorStore, PIISanitizer, OkapiBM25, Lost-in-the-Middle.
  - Тестирование переключения бэкендов `switch_backend.py` и dry run запуск Streamlit GUI.

## [2.1.1] — 2026-11-04

### 🛡️ Повышение надежности и стабильности клиентской части (Ноутбук / Arch Linux)

- **Ликвидация утечек дескрипторов SQLite (`api/session_manager.py`, `api/app.py`)**:
  - Внедрен финализатор `__del__` и явная очистка в lifespan-контексте FastAPI, исключающие зависание соединений базы сессий при завершении процессов (`ResourceWarning: unclosed database`).
- **Сетевая изоляция и обход прокси (`llm-ctl`, `server_manager.py`)**:
  - Все сетевые запросы `llm-ctl` снабжены флагом `--noproxy "*"`, исключая ложные таймауты и зависания виджета Waybar при активных VPN/системных прокси.
  - Улучшен переключатель IP `cmd_toggle_ip` с поддержкой wildcard-сопоставления и автопоиска `.env`.
- **Надежность оконного интерфейса на Wayland (`run_app.py`)**:
  - Добавлена функция `get_available_gui_backend()`, автоматически выбирающая оптимальный движок отрисовки (PyQt6-WebEngine или WebKit2GTK).
  - Установлен флаг `WEBKIT_DISABLE_DMABUF_RENDERER=1` для предотвращения мерцаний и падений WebKit2GTK в композиторах SwayFX / Hyprland.
  - Интегрированы нативные системные уведомления рабочего стола через `hyprctl notify` и `notify-send`.
- **Отказоустойчивость стриминга ответов LLM (`rag_remote_client.py`)**:
  - Добавлен перехват обрыва сетевого соединения (`httpx.NetworkError`, `APITimeoutError`) непосредственно в генераторе токенов с информативным исключением `ServerOfflineError`.
- **Многоадресный Wake-on-LAN (`server_manager.py`)**:
  - Модуль WoL теперь отправляет магический пакет на `255.255.255.255`, широковещательный адрес локальной подсети (напр. `192.168.x.255`), и задействует как порт 9, так и порт 7.
- **Потокобезопасный TTL-кэш телеметрии (`server_manager.py`)**:
  - Опрос статуса и здоровья сервера снабжен 2-секундным кэшем с блокировкой `threading.Lock`, предотвращая дублирующие HTTP-запросы при частой перерисовке виджетов Streamlit.
- **Безопасный автозапуск (`start.sh`)**:
  - Автоматическая инициализация `.env` из шаблона при первом старте и автоподключение `rag_index.json` с рабочего стола при его наличии.

## [2.1.0] — 2026-11-04

### 🌟 Ключевые нововведения (Распределенная инфраструктура и удаленный сервер)

#### 1. Серверный комплекс для Windows 11 + NVIDIA RTX 4070 (`pc_server/`)
- **Полнофункциональный FastAPI сервер (`server.py`)**: Реализована полная совместимость с OpenAI API (`/v1/chat/completions` со стримингом через Server-Sent Events, `/v1/embeddings` с 768-D векторами).
- **Административные эндпоинты управления VRAM**:
  - `GET /health` — мгновенная проверка статуса сервера и телеметрии (загруженная модель, активность эмбеддингов).
  - `GET /admin/models` — список доступных GGUF-моделей в директории `models/`.
  - `POST /admin/switch` — динамическая горячая загрузка выбранной модели в VRAM с настройкой контекстного окна (`ctx_size`).
  - `POST /admin/unload` — мгновенная выгрузка модели и освобождение 100% видеопамяти (VRAM down to 0 MB).
- **Асинхронная защита event loop (`model_manager.py`)**: Все тяжелые блокирующие вызовы генерации и загрузки весов вынесены в фоновые потоки (`asyncio.to_thread`), что исключает зависание эндпоинтов `/health` во время инференса.
- **Векторный движок эмбеддингов (`embedding_engine.py`)**: Локальный инференс `nomic-embed-text-v1.5` на CPU с L2-нормализацией векторов, гарантирующий 100% совместимость с базой знаний RAG без расхода драгоценной памяти GPU.
- **Многоуровневая безопасность (`auth.py`)**: Поддержка авторизации по Bearer Token с белым списком для быстрых проверок здоровья.

#### 2. Удаленный доступ из любых сетей (Any-Network Connectivity)
- **Tailscale WireGuard Mesh P2P (`setup_tailscale.ps1`)**: Автоматизированная настройка прямого зашифрованного соединения между ноутбуком и ПК через NAT и мобильные сети без белого IP и проброса портов.
- **Cloudflare Tunnel (`setup_cloudflare_tunnel.ps1`)**: Безопасный публичный HTTPS-доступ через глобальную сеть Cloudflare Edge.
- **Брандмауэр Windows (`setup_firewall.ps1`)**: Автоматическое открытие порта 8000 TCP для локальной сети.
- **Автозапуск службы Windows (`install_windows_service.ps1`)**: Регистрация сервера в качестве службы Windows (NSSM / WinSW) с автозапуском при старте системы.

#### 3. Встроенная интеграция в RAG-приложение (`RAG.exe-linux/`)
- **Графический интерфейс (`rag_gui.py`)**:
  - Добавлена вкладка **«⚡ Удаленный RTX 4070 (ПК / Любая сеть)»**.
  - Быстрый выбор пресетов подключения: *Tailscale (P2P)*, *Локальная сеть (LAN)*, *Cloudflare Tunnel (HTTPS)*, *Локальный Mock (127.0.0.1)*, *Пользовательский*.
  - Виджет телеметрии: пинг, статус связи, текущая модель, статус видеопамяти.
  - Управление: выпадающий список моделей сервера с кнопкой применения, кнопка очистки VRAM, кнопка отправки Wake-on-LAN пакета, кнопка запуска Mock-сервера.
- **Пайплайн и векторное хранилище (`rag_engine.py`)**:
  - Добавлен провайдер `RTX4070_REMOTE` в `AppConfig`.
  - Поддержка заголовков авторизации Bearer Token в `DenseVectorStore` и клиенте генерации.
- **Менеджер бэкендов (`server_manager.py`, `switch_backend.sh`)**:
  - Создан профиль `.env.rtx4070` с мгновенным переключением бэкенда.
  - Функции синхронизации настроек между RAG и общесистемным конфигом `~/.config/llm-remote/config.env`.

#### 4. Клиентский стек для Arch Linux (SwayFX / Waybar)
- **Утилита управления `llm-ctl`**:
  - Быстрый статус для Waybar с гарантированным таймаутом <1.0с (фактическое время отклика при выключенном ПК — 22.5 мс).
  - Интерактивное меню переключения моделей и пресетов сети через Rofi / Fuzzel (`$mod+m`).
  - Управление Wake-on-LAN и локальным эмулятором.
- **Локальный эмулятор (`mock_pc_server.py`)**:
  - Автономный FastAPI-сервер на `127.0.0.1:8000`, симулирующий все эндпоинты RTX 4070, стриминг и генерацию 768-D векторов для разработки без включения ПК.
- **Интеграция с рабочим окружением**:
  - Виджет Waybar (`waybar_module.jsonc`, `waybar_style.css`) в стилистике Samsung One UI 9 / Glassmorphism.
  - Горячие клавиши для SwayFX (`sway_snippet.conf`).
- **Python SDK (`rag_remote_client.py`)**:
  - Клиент `Remote4070Client` с типизированными исключениями `ServerOfflineError` и `NoModelLoadedError`.

## [1.0.0] — 2026-09-13

### ⚛️ Базовый релиз RAG 2.0 (SchoolX)
- **Двухуровневый гибридный поиск (Hybrid Retrieval)**:
  - Лексический поиск **Okapi BM25** с русским стеммингом (Snowball).
  - Семантический поиск по 768-мерным векторам (`nomic-embed-text-v1.5`).
  - Слияние рангов по алгоритму **Reciprocal Rank Fusion (RRF, k=60)**.
- **Борьба с деградацией контекста**: Алгоритм **Lost-in-the-Middle**, располагающий наиболее важные чанки по краям окна внимания.
- **Защита от галлюцинаций**: Zero-retrieval фильтрация, изоляция контекста в XML-тегах `<context>`, потоковый санитайзер от паразитных CJK-иероглифов.
- **Парсинг документов**: Поддержка форматов PDF, TXT, MD, DOCX, XLSX с метаданными.
- **Интерфейс**: Streamlit веб-интерфейс с разделами «Аналитика», «База знаний» и «Архитектура».
