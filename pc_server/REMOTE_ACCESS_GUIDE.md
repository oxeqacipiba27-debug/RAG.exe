# Полное руководство по удаленному подключению к RTX 4070 из любой внешней сети

Данное руководство объясняет, как сделать сервер на базе **Windows 11 + NVIDIA RTX 4070** доступным для вашего ноутбука (**Arch Linux + SwayFX + Waybar**) из **любой точки мира**: через мобильный интернет, отельный Wi-Fi, рабочую сеть или в поездках.

---

## 🧭 Проблема и архитектурные решения

В локальной сети (LAN) устройства видят друг друга напрямую по адресам вида `192.168.1.x`. Но как только ноутбук покидает домашний Wi-Fi:
1. Домашний роутер блокирует входящие соединения из интернета по соображениям безопасности.
2. Большинство интернет-провайдеров используют **CGNAT (серый IP)**, из-за которого прямой доступ по белому IP невозможен без специальных туннелей.
3. Открытие порта 8000 напрямую в интернет без защиты открывает вашу видеокарту для несанкционированного доступа.

Мы предоставляем **3 проверенных решения**, оптимизированных под разные сценарии:

| Способ | Сложность | Требует белый IP? | Проброс портов? | Безопасность | Рекомендация |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **1. Tailscale (WireGuard Mesh)** | ⭐ (1 мин) | ❌ Нет | ❌ Нет | 🔒 Максимальная (WireGuard E2E) | **ТОП-1 (Рекомендуется)** |
| **2. Cloudflare Tunnel** | ⭐⭐ (3 мин) | ❌ Нет | ❌ Нет | 🔒 Высокая (Cloudflare Edge) | Отлично для HTTPS |
| **3. Router Port Forwarding + API Key** | ⭐⭐⭐ (5 мин) | ✔ Да | ✔ Да (роутер) | ⚠️ Нужен сложный API Token | Если есть белый IP |

## 🥇 Способ 1: Tailscale (Рекомендуемый выбор)

### Почему Tailscale идеален:
- **Zero-Config:** Не требует белого IP, не требует проброса портов, обходит CGNAT любой строгости.
- **Сквозное шифрование (WireGuard):** Трафик между вашим ноутбуком и ПК шифруется напрямую P2P.
- **Статический IP:** ПК получает постоянный виртуальный IP в сети `100.x.y.z` и MagicDNS имя (например, `rtx4070-pc`), который **никогда не меняется**, даже если домашний провайдер меняет IP.

### Шаг 1. Настройка на Windows 11 (Сервер с RTX 4070)
В папке `pc_server` запустите автоматический помощник:
```powershell
powershell -ExecutionPolicy Bypass -File .\setup_tailscale.ps1
```
Либо вручную:
1. Скачайте и установите Tailscale: [tailscale.com/download/windows](https://tailscale.com/download/windows) (или `winget install Tailscale.Tailscale`).
2. Войдите в аккаунт (Google / GitHub / Microsoft).
3. Помощник или команда `tailscale ip -4` выведет ваш удаленный IP, например:
   ```text
   100.84.120.45
   ```

### Шаг 2. Настройка на Arch Linux (Ноутбук)
1. Установите и включите Tailscale:
   ```bash
   sudo pacman -S tailscale
   sudo systemctl enable --now tailscaled
   ```
2. Подключитесь под тем же аккаунтом:
   ```bash
   sudo tailscale up
   ```
3. Проверьте пинг до Windows ПК:
   ```bash
   ping -c 3 100.84.120.45
   ```

### Шаг 3. Привязка к клиенту RAG и Waybar
Откройте конфиг `~/.config/llm-remote/config.env` на ноутбуке:
```env
# Указываем Tailscale IP вместо 127.0.0.1
LLM_SERVER_IP="100.84.120.45"
LLM_SERVER_PORT="8000"

# LAN IP для быстрого переключения в меню по кнопке "Switch IP"
REAL_SERVER_IP="192.168.1.100"
```
Либо выполните быструю замену одной командой:
```bash
sed -i 's/^LLM_SERVER_IP=.*/LLM_SERVER_IP="100.84.120.45"/' ~/.config/llm-remote/config.env
```

**Проверка:**
В терминале ноутбука выполните:
```bash
llm-ctl status
```
Waybar сразу покажет: `󰚩 Qwen2.5-14B` или статус модели, даже если вы раздаете интернет на ноутбук с телефона в другой точке города!

## 🥈 Способ 2: Cloudflare Tunnel (`cloudflared`)

Cloudflare Tunnel создает защищенный исходящий туннель из Windows ПК в глобальную сеть Cloudflare, выдавая защищенный HTTPS адрес без открытых портов.

### Шаг 1. Запуск на Windows 11
В папке `pc_server` запустите:
```powershell
powershell -ExecutionPolicy Bypass -File .\setup_cloudflare_tunnel.ps1
```
Скрипт автоматически скачает официальный `cloudflared.exe` и выведет в терминал адрес:
```text
https://my-rag-inference.trycloudflare.com
```

### Шаг 2. Настройка клиента на ноутбуке
В `~/.config/llm-remote/config.env` укажите сгенерированный домен или используйте его в `Remote4070Client`:
```python
from rag_remote_client import Remote4070Client

client = Remote4070Client(host="my-rag-inference.trycloudflare.com", port=443)
```

## 🥉 Способ 3: Проброс портов на роутере + Авторизация по API-ключу

Если у вашего домашнего провайдера есть **белый статический IP** или вы используете **DDNS** (DuckDNS, No-IP):

### Шаг 1. Включение защиты API-токеном на сервере
При выходе напрямую в публичный интернет **обязательно** включите парольную защиту сервера.
Откройте файл `pc_server/.env` на Windows 11:
```env
# Задайте сложный секретный токен:
PC_SERVER_API_KEY="sk-rtx4070-super-secret-token-xyz789"

# Разрешить Waybar опрашивать /health без пароля:
PC_SERVER_ALLOW_UNAUTH_HEALTH=true
```

### Шаг 2. Проброс порта на домашнем роутере
1. Зайдите в веб-интерфейс роутера (обычно `192.168.1.1`).
2. Найдите раздел **Port Forwarding / Виртуальные серверы**.
3. Добавьте правило:
   - Внешний порт: `8000`
   - Внутренний порт: `8000`
   - Внутренний IP: IP адрес вашего Windows ПК (например, `192.168.1.100`)
   - Протокол: `TCP`

### Шаг 3. Правило Брандмауэра Windows Defender
Выполните от Администратора в PowerShell:
```powershell
powershell -ExecutionPolicy Bypass -File .\setup_firewall.ps1 -Action allow
```

## 💡 Управление электропитанием и Wake-on-LAN через интернет

Чтобы удаленно подключаться к серверу, ПК не обязательно должен работать на полной мощности 24/7:
1. **Предотвращение случайного сна при включенном сервере:**
   В настройках электропитания Windows 11 (Параметры -> Система -> Завершение работы и батарея):
   - `При питании от сети переводить компьютер в спящий режим`: установите **Никогда** (видеокарта в режиме `unload` потребляет всего 10–14 Вт в простое).
2. **Wake-on-LAN из внешней сети:**
   - Если используется Tailscale, вы можете включить функцию **Tailscale Subnet Router** на роутере или втором маломощном устройстве (Raspberry Pi / мини-ПК), что позволит отправлять WoL пакет `llm-ctl wake` даже из внешней сети!

## 🛠️ Сводка проверочных команд

| Действие | Команда на Windows 11 | Команда на Arch Linux |
| :--- | :--- | :--- |
| **Проверка статуса** | `.\run_server.ps1` | `llm-ctl status` |
| **Тест здоровья** | `curl http://127.0.0.1:8000/health` | `curl http://${LLM_SERVER_IP}:8000/health` |
| **Смена модели** | Через API или `run_server` | `llm-ctl switch <model.gguf>` |
| **Освобождение VRAM** | `curl -X POST http://127.0.0.1:8000/admin/unload` | `llm-ctl unload` |
| **Tailscale IP** | `tailscale ip -4` | `tailscale status` |
| **Интерактивное меню**| — | `llm-ctl menu` (Super+M / Waybar) |
